Detailed Description

Base for typedef t_note.

An struct to characterize a note in several useful notation types.

Field Documentation

◆ chrom

s_note::chrom

The chromatic interval of this note from the C note of it same octave. A C = 0, C# = 1, D = 2... B = 11.

◆ dia_alteration

s_note::dia_alteration

A value of 0 if no alteration. A value of 1 for a semi-tone above the value of s_note::pse_diaton

◆ midi

s_note::midi

The absolute midi value if received from a keyboard. Theoretically it could be anything from 0 to 127.

◆ octave

s_note::octave

The octave (see define PT_MIDI_60_MIDDLE_C_OCTAVE).

◆ pse_diaton

s_note::pse_diaton

The position in the C major escale in a diatonic sense (but starting at 0). For example C = 0, D = 1, E = 2... B = 6. It's complemented with the value of dia_alteration.
